# Project Screenshots

Store the important screenshots/photos of CRQ Platform in this folder.

## Recommended screenshots

- Login screen
- Overview (Demo) dashboard with a completed simulation
- Ingestion Engine (Own Data upload + findings review)
- Investment optimizer
- Ledger (blockchain-backed audit trail)
- Calibration
- Reports (framework coverage matrix)
- Training - Platform Navigation Guide
- CRQ Intelligence rollup view

## Naming convention

Use clear names such as:

- `01-login.png`
- `02-overview-demo.png`
- `03-ingestion-own-data.png`
- `04-investment-optimizer.png`
- `05-ledger.png`
- `06-calibration.png`
- `07-reports.png`
- `08-training-nav-guide.png`
- `09-crq-intelligence.png`

Do not upload screenshots containing passwords, API keys, tokens, personal credentials, or other sensitive information.

## Adding screenshots to README

You can display important screenshots in the main `README.md` using a relative path, for example:

```md
![CRQ Intelligence](assets/screenshots/09-crq-intelligence.png)
```
